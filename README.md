# Filelink

在 WPS 窗口中**一键复制当前文档的本地完整路径**的轻量悬浮工具（Windows / AutoHotkey v2）。

## 背景

WPS 标签页右键菜单里的「复制链接」复制的是云端分享链接，而不是文件的本地路径，且官方没有提供复制本地路径的按钮。Filelink 就是为了补上这个缺口。

## 功能特性

- 🔗 **透明悬浮图标**：只在 WPS（文字 / 表格 / 演示 / PDF）窗口激活时显示，切走自动隐藏，无托盘图标，完全无感
- 📋 **单击复制路径**：解析 WPS 窗口标题中的文件名，在注册表 `HKCU\Software\Kingsoft\Office\6.0\<组件>\RecentFiles` 中精确匹配出完整本地路径并复制到剪贴板
- 🖱️ **按住拖动**：把图标拖到任意位置，松手后自动固定
- 💾 **位置记忆**：固定位置保存在 `settings.ini`，重启后自动恢复
- 📌 **右键菜单**：固定在当前位置 / 恢复跟随窗口右上角 / 退出
- 🪶 **轻量**：内存占用约 15 MB，支持开机自启

## 运行环境

- Windows 10 / 11
- [AutoHotkey v2](https://www.autohotkey.com/)（便携版即可，无需安装）
- WPS Office

## 使用方法

1. 安装或解压 AutoHotkey v2
2. 用 `AutoHotkey64.exe` 运行 `Filelink.ahk`
3. 打开任意 WPS 文档，窗口右上角会出现 🔗 图标
4. **单击图标** → 当前文档的本地路径已复制，直接粘贴使用
5. **按住拖动图标** → 移动到喜欢的位置，松手自动固定并记住
6. **右键图标** → 固定 / 恢复跟随 / 退出

### 开机自启

在 `Win + R` → `shell:startup` 打开的启动文件夹中创建快捷方式：

- 目标：`"C:\路径\AutoHotkey64.exe" "C:\路径\Filelink.ahk"`
- 运行方式：最小化

## 工作原理

1. 每 400ms 检测前台窗口进程是否为 WPS（`wps.exe` / `et.exe` / `wpp.exe` / `wpspdf.exe`），是则显示图标，否则隐藏
2. 点击时读取 WPS 窗口标题（格式为 `完整文件名 - WPS Office`），剥离后缀与前缀（如「只读」）得到文件名
3. 在注册表 WPS 最近文件列表中按文件名匹配，返回文件真实存在的完整路径
4. 仅存放在 WPS 云文档、无本地实体的文件会提示「未找到本地路径」

## 配置项（脚本顶部）

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `BTN_OFFSET_RIGHT` | 跟随模式：距窗口右边缘像素 | 60 |
| `BTN_OFFSET_TOP` | 跟随模式：距窗口顶部像素 | 90 |
| `ICON_SIZE` | 图标尺寸 | 36 |
| `CHECK_INTERVAL` | 前台窗口检测间隔（毫秒） | 400 |
